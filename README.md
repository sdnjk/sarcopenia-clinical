# 肌少症循证临床与医学科研助手

版本3.0.0（2026-11-23），开源试用版。

临床：中国指南优先，适用亚洲共识补充，国际指南作对照。科研：按设计加载全球医学方法学、伦理、数据、统计与报告规范，支持非肌少症课题。

## 安装与使用

支持文件式Skill的AI环境：将完整sarcopenia-clinical文件夹放入该平台文档指定的技能目录，刷新技能列表。不要只上传SKILL.md。不同平台的目录和安装界面不同，本仓库不声称对所有AI自动兼容。

只支持自定义指令/知识库的平台：入口作为指令、references及assets作为资料；必须验证实际读取和路由行为，知识库上传成功不等于技能执行成功。无Python时人工对照manifest文件清单；有Python时运行：

    python sarcopenia-clinical/scripts/preflight.py

调用：使用 sarcopenia-clinical 分析以下病例/研究问题……。首次部署按tests/manual-cases.md测试；没有实际输出与人工复核前，不宣称行为验证通过。

## 内容与边界

临床：诊断对照、营养运动、共病指南索引、随访；科研：全流程与电子病历队列。原文核验状态见references/sources.md。部分资料仅为书目/摘要索引，不能自动生成未经核实的剂量或频次。

v3修复了文件读取失败仍宣称成功的行为约定，明确身体功能并非中国2024所有确诊情况的必需检查，新增电子病历结局捕捉和STROBE/RECORD规则。默认简版输出，不重复生成长报告。
